# Figma Export

Статический HTML-снимок портфолио — для импорта в Figma через плагин.

## Как загрузить в Figma

1. Открой Figma → **Plugins** → найди и установи один из плагинов:
   - **html.to.design** (рекомендую)
   - **Builder.io** → Figma
   - **Figma to HTML, CSS, React & more**
2. Запусти плагин, выбери **Import from file** → загрузи `index.html`
   (или открой `index.html` в браузере и скопируй URL `file://...` —
   некоторые плагины умеют импортировать по URL).
3. Плагин разложит макет на фреймы и слои.

В файле два artboard'а: **Desktop 1440×900** и **Mobile 390×844**.

## Что не вошло

- Анимации (падающие блоки сборки продукта, motion-эффекты) — остаются
  только в живом приложении. В Figma попадает финальное визуальное
  состояние.
- Драг-н-дроп иконок, открытие окон — статичный снимок.

## Ассеты

Иконки и фоновые картинки лежат в `assets/` и подключены по относительным
путям. Если переносишь `index.html` отдельно — забери папку `assets/` с ним.
