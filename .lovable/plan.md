## Изменения в десктопной версии (`src/routes/index.tsx`)

### 1. Убрать окно Zoom meeting
Полностью удалить компонент/блок Zoom-окна с рабочего стола и связанные ассеты-импорты, если они больше нигде не используются.

### 2. Заметка + хаотичное расположение + drag&drop
- Увеличить размер «Заметки» (note) примерно на ~15–20% относительно текущего (с `w-32 h-32` до `w-40 h-40`, шрифт чуть крупнее).
- Перейти от жёсткой колоночной сетки к свободному размещению: каждая иконка получает абсолютные координаты `{x, y}` на холсте рабочего стола.
- Начальная раскладка — намеренно хаотичная (разные углы экрана, лёгкие повороты `rotate(-3deg…3deg)`), НО кейсы-папки (Crypto, 4Dev, Должник прав, EatEasy, Aqua и т.п.) сгруппированы рядом в одном «облаке», чтобы читалась иерархия «папки = проекты».
- Добавить drag-and-drop: 
  - Состояние `positions: Record<id, {x:number,y:number}>` в `useState`.
  - На каждой иконке `onPointerDown` → захват, `onPointerMove` (на window) → обновление координат с учётом offset, `onPointerUp` → отпускание.
  - Ограничение в пределах контейнера рабочего стола; курсор `grab`/`grabbing`.
  - Сохранение позиций в `localStorage` (ключ `desktop-icon-positions`), чтобы при перезагрузке расклад пользователя сохранялся; кнопка/жест сброса не требуется.
- Двойной клик / одиночный клик по-прежнему открывает содержимое — drag отличаем по порогу смещения (>4px = drag, иначе click).

### 3. Более объёмные и интерактивные папки
Переписать `IconGraphic` варианта `folder`:
- Многослойная SVG-папка: задняя вкладка, основной корпус, передняя «створка» со скосом, внутренняя тень и блик сверху.
- Лёгкий 3D-эффект через градиенты (`linear-gradient` тёплой охры → более тёмный край) + мягкая тень снизу (`drop-shadow`).
- Hover: масштаб `scale(1.06)`, передняя створка чуть «приоткрывается» (translateY + rotateX через CSS transform), усиливается тень.
- Active (нажатие): лёгкое сжатие `scale(0.97)`.
- Микро-наклейка с эмодзи/буквой проекта на корпусе папки (Crypto → ₿, 4Dev → </>, Должник → ⚖, EatEasy → 🍽, Aqua → 💧) для узнаваемости.

### 4. Одинаковый размер «Галерея» и «Figma» (фирма)
Сейчас «Галерея» рендерится крупнее. Унифицировать:
- Обе иконки получают одинаковый бокс `w-32 h-32` и одинаковый внутренний `IconGraphic` `w-28 h-28`.
- Подпись — одинаковый `text-[15px]`, одинаковый отступ.

### 5. Динамический градиентный фон десктопа
Заменить текущий статичный radial-gradient на многослойный анимированный:
- Основа: `conic-gradient` + два `radial-gradient` пятна тёплых тонов (#ece6dc, #d9d0bf, мягкий розово-персиковый акцент, прохладный серо-голубой акцент).
- Лёгкая анимация: keyframes `background-position` или перемещение позиций пятен (через CSS-переменные + `@keyframes`), длительность ~20–30с, ease-in-out, бесконечно — движение очень мягкое, не отвлекает.
- Сохранить «бумажную» зернистость (`.grain`) поверх.

### 6. Виджет локации — Москва
Добавить на рабочий стол небольшой виджет-карточку (~`w-44`), располагается в правом верхнем углу по умолчанию (тоже draggable):
- Заголовок «Москва», под ним текущая дата (короткий формат, локаль `ru-RU`) и время `HH:MM` с обновлением раз в минуту через `useEffect` + `setInterval`.
- Иконка погоды/локации (📍 или мини-SVG булавки) + строка «MSK · UTC+3».
- Стиль карточки: матовое стекло (`backdrop-blur`, полупрозрачный фон `bg-white/40`, тонкая граница, мягкая тень) — в духе iOS-виджетов.
- Данные статические (без запроса погоды) — это чисто визуальный виджет локации.

### Технические детали
- Все изменения только в `src/routes/index.tsx` (+ возможный мелкий keyframes-блок в `src/styles.css` для анимации фона).
- Никаких новых зависимостей: drag реализуем на нативных pointer events.
- Mobile-вьюпорт (телефон-мокап) не трогаем — изменения только под `md:`/desktop ветку.
- Проверить, что после удаления Zoom не осталось «висячих» импортов SVG.
