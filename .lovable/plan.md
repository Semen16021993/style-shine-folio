# План: HTML-экспорт портфолио для Figma

## Что делаю

Создаю отдельную папку `figma-export/` в корне проекта со статическим HTML-файлом, который содержит всё портфолио в виде, удобном для импорта в Figma через плагин **html.to.design** (или аналогичный).

## Структура

```text
figma-export/
  index.html          — единый автономный HTML со всеми блоками портфолио
  README.md           — короткая инструкция: как загрузить в Figma через плагин
  assets/             — копии нужных SVG/изображений (иконки, фон), на которые
                        ссылается index.html по относительным путям
```

## Содержимое index.html

Один файл, без сборки и без внешних зависимостей (плагины импорта плохо
работают с React/JS-рендером — им нужен готовый DOM):

1. **Десктоп-сцена** — фон, sticky-note с заметкой, виджет локации (Москва),
   все иконки на рабочем столе (Cryptowallet, 4Dev, Должник, Галерея, Figma, CV)
   в их финальных позициях.
2. **Открытая папка Cryptowallet** — как отдельная секция ниже, со всеми
   блоками контента и одинаковыми отступами.
3. **Страница CV** — структурированный блок с опытом, навыками, стеком.
4. **Мобильная версия** — отдельный artboard 390×844 ниже десктопа, чтобы
   в Figma сразу было два фрейма.

Все стили — инлайн `<style>` в `<head>`, без Tailwind и без CSS-переменных
(плагины импорта стабильнее работают с развёрнутыми значениями цветов и
размеров). Шрифты подключаются `<link>` на Google Fonts — плагин подхватит
названия и подменит на ближайшие в Figma.

## Что НЕ переношу

- Анимации (Framer Motion, падающие блоки сборки продукта) — в статичном
  HTML их нет смысла экспортировать; в Figma всё равно станут статикой.
  В заметке в README укажу, что анимации остаются только в живом приложении.
- Интерактив (перетаскивание иконок, открытие папок) — только финальные
  визуальные состояния.

## Инструкция в README.md

Коротко:
1. Открыть Figma → Plugins → html.to.design (или Figma to HTML, builder.io).
2. Загрузить `figma-export/index.html`.
3. Получить готовые фреймы desktop + mobile с разложенными слоями.

## Технические детали

- Файлы кладу вне `src/`, чтобы Vite их не обрабатывал и они не попадали
  в бандл приложения.
- Иконки беру из `src/assets/` (SVG) и копирую в `figma-export/assets/`,
  чтобы папка была самодостаточной и её можно было заархивировать и отправить.
- Цвета, размеры и позиции беру 1-в-1 из текущего `src/routes/index.tsx`,
  чтобы экспорт визуально совпадал с превью.
